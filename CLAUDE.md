# Carbon

## README

`README.md` is Carbon's user-facing description: what a person sees and does. Keep it current. A change to anything a person sees or does updates the README line about it in the same PR, as do the README's screenshot and its Credits when a bundled model or library changes. That covers the menu bar, notifications, Settings, Meeting Languages, the Markdown file and Privacy. A PR is done once every README sentence it touches still holds.
